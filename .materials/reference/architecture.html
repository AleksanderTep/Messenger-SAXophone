Оглавление

Архитектура прототипа

Стек: Python/FastAPI принимает HTTP и возвращает JSON; PostgreSQL хранит данные; React описывает интерфейс; TypeScript проверяет типы; Vite запускает и собирает клиент. Nginx раздаёт сборку и направляет /api в backend.

Объём: регистрация, вход, просмотр профиля, выход, API поиска пользователей. Ошибки и сценарии описаны в api-contract.md и user-stories.md. Личные диалоги, отправка сообщений, WebSocket, поиск сообщений, редактирование профиля, внешний CD не входят в финальный результат. Таблицы чатов — задел схемы, не работающая функция.

В этой ветке публикуется описание архитектуры существующего прототипа по пересмотренному плану; реализация не включена. SVG можно открыть прямо в браузере, .mmd — редактируемый исходник.
