# Отчёт по спринту 2

Тема: Архитектура проекта. Контрольная дата нового плана — 21.10.2026. Отчёт составлен 28.10.2026. Новый план не меняет фактические даты коммитов и подготовки материалов.

## Цель и результат

Описаны границы системы, стек, данные, экраны, сценарии и HTTP-контракт. React обращается через Nginx/Vite к FastAPI, сервер работает с PostgreSQL через SQLAlchemy. Финальный объём — регистрация, вход, просмотр профиля, выход и API поиска пользователей.

## Что показать

Контекст, компоненты, развёртывание, полная ERD и экраны находятся в reference/diagrams. Стек, API с примерами, четыре user stories и стратегия проверок — в reference. Таблицы чатов являются заделом схемы, не работающей перепиской.
