Границы и связи

Браузер → pages.tsx → функции App.tsx → api.ts → HTTP API → auth.py → users.py/security.py → models.py/db.py → PostgreSQL.

main.py связывает сервер; /health проверяет процесс, /ready выполняет SELECT 1 и при ошибке БД возвращает 503. User/AuthSession участвуют в авторизации; Chat/ChatMember/Message — неиспользуемый задел переписки.

Dockerfile описывает сборку образа; Compose — сервисы, сеть, зависимости и volume; Nginx — раздачу клиента и proxy; workflow CI — автоматические проверки. Эти конфигурации здесь описаны, а не включены как работающая поставка.

На клиенте protect() решает, показать профиль, загрузку, ошибку или отправить гостя на вход; сервер независимо проверяет сессию. Форма и профиль получают данные обычными props.
