# Подготовка рабочего места

Нужны Git, Python 3.12, Node.js 22/npm, Docker Desktop с Compose, редактор и доступ к GitHub/Pyrus. Проверить версии: git --version; python --version; node --version; npm --version; docker compose version.

Клонировать репозиторий: git clone git@github.com:scorpdestroy/Messenger-SAXophone.git . Перед работой проверить git status и текущую ветку; авторство задавать своими реквизитами.

Node.js выполняет инструменты разработки; npm устанавливает зависимости; браузер отображает интерфейс. Позднее в ветке приложения npm ci устанавливает зафиксированные зависимости. Здесь package.json и приложение ещё не включены, запускать npm ci из этого снимка не нужно.

Аналогично Python venv изолирует зависимости, но requirements, сервер и Compose появятся в реализации. В этих снимках готовится окружение и документация, приложение не запускается.

Личное задание Артёму: перечислить понятные и сложные темы Python/HTTP/БД. Александру: компоненты/props/state/события/маршруты. Личные ответы заполняют сами участники.
