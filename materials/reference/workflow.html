Оглавление

Организация работы

Pyrus: задача содержит владельца, спринт, срок, критерии приёмки и ссылку на результат. Статусы: To Do → In Progress → Code Review → Testing → Done; переходы по фактической готовности.

Git: ветка задачи → понятный commit → push → pull request → review другого участника → CI → merge. main — демонстрационная версия; develop — интеграция; release/0.1.0 — кандидат релиза, без утверждения о завершённой приёмке.

sprint/1-setup, sprint/2-architecture, sprint/3-structure — накопительные тематические снимки пересмотренного плана. Они созданы сейчас, не меняют даты старых коммитов и не являются ветками поставки приложения.

Пароли и ключи не включаются в репозиторий. Участник показывает собственный результат и называет фактическую помощь коллег.
