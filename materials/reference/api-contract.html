Оглавление

Контракт существующего API

В браузере адреса имеют префикс /api; proxy убирает его перед FastAPI. Формат ошибки: {"error":{"code":"...","message":"..."}}.

МетодBackend-путьВходОтвет
GET/health—200 status/service; проверка процесса
GET/ready—200 при доступной БД; 503 при ошибке БД
POST/auth/registerusername, email, password, display_name?201 UserPublic; 400; 409
POST/auth/loginidentity, password200 access_token/token_type/expires_in/user; 400; 401
POST/auth/logoutBearer204 без тела; 401
GET/users/meBearer200 UserPublic; 401
GET/usersBearer, query, limit200 UserSummary[]; 400; 401

UserPublic: id, username, email, display_name. UserSummary: id, username, display_name. Поиск не показывает почту, исключает себя и ограничен 1–50 результатами; пустой query возвращает []. Это поиск пользователей, а не сообщений.

Логин: 3–32 латинские буквы/цифры/_, внешние пробелы удаляются, регистр понижается. Email приводится к нижнему регистру, ограничен 254 символами. Пароль регистрации: 10–128 символов, не обрезается. Отображаемое имя: до 80 символов; пустое заменяется логином.

Подпись JWT — HS256. Проверяются sub, jti, iat, exp, iss, aud и запись auth_sessions. В development без AUTH_SECRET_KEY создаётся ключ процесса; для постоянных сессий нужен постоянный ключ окружения. Полного refresh-token потока нет: после истечения нужен новый вход.

Endpoint создания чата, отправки сообщения и WebSocket в финальном API отсутствуют.

Примеры запросов и ответов

POST /auth/register: {"username":"student_demo","email":"student_demo@example.test","password":"Example-only-password-123","display_name":"Участник"}. Данные вымышленные. Ответ 201: id, username, email, display_name; без hash.

POST /auth/login: {"identity":"student_demo","password":"Example-only-password-123"}. Ответ 200: access_token, token_type="bearer", expires_in, user. Реальный токен в документ не включается.

GET /users/me и POST /auth/logout требуют Authorization: Bearer <access_token>. Logout возвращает 204 без тела; прежний токен затем получает 401. GET /users?query=student&limit=10 возвращает id/username/display_name без email, исключает себя.

Пример 409: {"error":{"code":"http_409","message":"Username or email already registered"}}. Ошибка ввода: {"error":{"code":"validation_error","message":"Invalid request"}}. На публичном адресе перед путём добавляется /api.
