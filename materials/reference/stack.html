Оглавление

Выбор технологий

Backend Артём

Python позволяет описывать серверные операции прямыми функциями. FastAPI связывает HTTP-маршруты и модели, публикует OpenAPI. Pydantic проверяет поля; SQLAlchemy описывает таблицы и запросы; Alembic управляет схемой; PostgreSQL обеспечивает транзакции и ограничения. Стек уже используется в коде и тестах, смена перед защитой не требуется.

GET получает данные/состояние, POST выполняет действие: GET /health и POST /auth/register. Формат обмена JSON. Сервер проверяет ввод независимо от клиента.

Frontend Вячеслав

React связывает интерфейс с состоянием компонента; TypeScript проверяет типы; Vite обеспечивает запуск и сборку. Props передают данные между компонентами, state хранит изменяемые значения. Для существующих форм отдельное глобальное хранилище не требуется.

Окружение Вадим

Docker даёт общий способ сборки и запуска. Compose связывает сервисы и готовность зависимостей, volume сохраняет БД. Nginx раздаёт frontend и проксирует API; CI проверяет push/PR. Внешний production и CD не настроены.

Ограничения: зависимость от Docker и портов, необходимость понимать настройки БД/сети. Полного refresh-token потока нет. Это обоснование учебного прототипа, не заключение о production-безопасности.
