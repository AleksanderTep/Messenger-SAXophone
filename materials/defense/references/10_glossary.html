Оглавление

Краткий словарь

HTTP — запрос и ответ между клиентом и сервером. Endpoint — пара метода и пути. JSON — формат данных. 200 — успех, 201 — создано, 204 — успех без тела, 400 — неверный ввод, 401 — нет действующей авторизации, 409 — конфликт, 503 — сервисная зависимость недоступна.

Hash — одностороннее представление пароля; его нельзя использовать как обычное шифрование для получения пароля обратно. Salt — случайная добавка для уникальных hash. JWT — подписанный набор claims, не контейнер для открытого пароля. Session — серверная запись, позволяющая отозвать токен.

ORM model — описание таблицы в коде. Migration — управляемое изменение схемы. Transaction — операция с commit или rollback. Unique index — защита от дубликатов в самой БД.

Component — часть интерфейса. Props — входные параметры компонента. State — меняющееся состояние. Context — общий доступ к состоянию в дереве React. sessionStorage — хранилище вкладки, не серверная БД.

Container — изолированный процесс со средой. Compose — описание совместного запуска контейнеров. Nginx proxy — передача запросов в backend. Volume — постоянное хранилище данных. CI — автоматические проверки; CD — автоматическое развёртывание, которого на внешнем сервере пока нет.

Commit — сохранённое изменение Git с автором, датой и родителем. Branch — указатель на commit. PR — предложение объединить ветку. Автор PR и author отдельных commits могут отличаться. Merge сохраняет связь историй; squash объединяет изменения в один commit и для этой серии не использовался.
